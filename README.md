## How I Work / 我怎么做

1. **先把问题变成可执行的工作流**：明确输入、边界、工具调用和交付结果。
2. **让结果带着证据**：保留来源、时间、缺失项、运行记录和可以复核的中间状态。
3. **缺失不伪造**：没有数据就明确标注，不用看起来完整的假值掩盖不确定性。
4. **把验证放回闭环**：测试、回测、运行复盘、修复和再次验证都属于产品的一部分。
